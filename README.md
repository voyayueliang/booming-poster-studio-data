# Booming Poster Studio Data

Public release data for the Booming poster editor.

- `projects/<project-id>/latest.json` is the fixed latest release read by the shared viewer.
- `projects/<project-id>/versions/` keeps immutable release snapshots.
- `projects/<project-id>/assets/` stores public uploaded logos and public registration QR codes.

Only public-recruitment posters and WeChat header images belong here. Directed-invitation posters and private QR codes must never be published to this repository.
